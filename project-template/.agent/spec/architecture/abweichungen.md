# Bekannte Abweichungen/Schulden

> Teil von `README.md` (Index). Stellen, an denen das Ist (`ist.md`)
> bewusst oder nachweislich vom Soll (`ziel.md`) abweicht – mit Verweis auf
> den Report/Task, der das dokumentiert hat. Kein Ort für neue,
> unbestätigte Vermutungen. Was hier steht, ist im `REVIEW` kein neues
> Finding.
